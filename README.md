## Proyecto Strategy vs Template Method
Este repositorio contiene un ejemplo gráfico en Java que muestra el funcionamiento de los patrones de diseño Strategy y Template Method.
Incluye:
- Código fuente funcional
- Interfaz gráfica para interactuar con ambos patrones
- Archivo con el historial de prompts y respuestas generadas por IA
El objetivo es evidenciar tanto la implementación como el proceso de generación del código.
